SimcirJS

SimcirJS (a.k.a. Simcir) is a circuit simulator built with HTML5 and JavaScript. Design and simulate digital logic circuits directly in your browser.

Usage

  • Choose a device from the toolbox and move it to the workspace.
  • Drag between nodes to connect them.
  • Click an input node to disconnect.
  • Drag a device back to the toolbox to remove it.
  • Ctrl+Click (Cmd+Click on Mac) to switch between the live circuit and JSON data views.
  • Double-click a label to edit the device name.
  • Double-click a library device to open the circuit inside.

Quick Embed

Include the library files and add a div.simcir with your circuit JSON:

<!doctype html> <html> <head> <script src="https://cdn.jsdelivr.net/gh/crimaniak/simcirjs@main/simcir.js"></script> <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/crimaniak/simcirjs@main/simcir.css" /> <script src="https://cdn.jsdelivr.net/gh/crimaniak/simcirjs@main/simcir-basicset.js"></script> <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/crimaniak/simcirjs@main/simcir-basicset.css" /> <script src="https://cdn.jsdelivr.net/gh/crimaniak/simcirjs@main/simcir-library.js"></script> <title>My Circuit</title> </head> <body> <div class="simcir"> { "width": 600, "height": 300 } </div> </body> </html>
