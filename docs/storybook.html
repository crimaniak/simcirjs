Node customization (portRadius / rectanglePadding / portPadding)

Devices can customize their ports: portRadius (default 4) is the port circle radius, rectanglePadding (default 0) adds space between the ports and the device drawing (when only portRadius is set, padding is derived so this space stays at its default), and portPadding (default 0) moves the ports inward from the device edges. Here: NAND uses a radius of 8, AND pads its edges by 4, XOR moves its ports inward by 3, and the LED uses radius 5 plus padding 3.

{"showToolbox":true}

Schema-level node defaults (portRadius / rectanglePadding / portPadding)

The same three options can be set once on the schema itself, and every device that does not specify its own value inherits them. This schema uses portRadius: 6, rectanglePadding: 2, and portPadding: 1: the DC, Toggle, NAND, and LED inherit all three, while the AND overrides them back to 4/0/0.

{"showToolbox":true}
